# Landing page example

This folder contains a simple **static landing page** (no build step).

## Open it

- Double-click `index.html`, or
- Serve the folder locally (optional):

```bash
python3 -m http.server 5173
```

Then visit `http://localhost:5173`.

## Files

- `index.html`: page markup
- `styles.css`: styling (includes light/dark theme vars)
- `script.js`: theme toggle, mobile menu, simple email validation
